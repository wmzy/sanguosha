# AI Arena Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. User authorizes delegated research and focused implementation; run consolidated checks after the substantial implementation.

**Goal:** 多模型正常对战，独立上下文，观众全手牌且身份保密，完整记录归档。

**Architecture:** 复用 HGC/REST/SSE；src/arena 提供共享观察、决策、归档、API 运行器。MCP 调用共享会话；服务端提供观众快照与归档读取，前端提供简单观众页。

**Tech Stack:** TypeScript, Node fetch, Hono, existing React and Vitest.

**Spec:** docs/superpowers/specs/2026-11-08-ai-arena-design.md

## Global Constraints
- 玩家输入绝不复用观众输入；身份只对本人、主公和死亡角色可见。
- 私密看牌仅操作者可见，公开展示可被全体看到，牌堆未观察部分保持未知。
- 不制作成片，不做高要求安全或强稳定性；主功能完成后集中测试。
- 当前工作目录原地使用 codex/ai-arena 分支；不自动提交或推送。

## Review Focus
- AI 视图和策略日志是否不含他人隐藏信息。
- 观星提示的完整牌面是否实际进入操作者输入，其他人不可见。
- 多目标/分配/看牌整理类操作能否正常提交。
- 外部 MCP 接替座位与 API 玩家能否一起推进普通房间。
- 对局结束/中断后归档是否完整且独立于房间清理。
