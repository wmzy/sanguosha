## 技能详解

### 界狂骨（被动技）

> **机制简述**：对距离1角色造伤后回血或摸牌

**官方效果**：当你对距离1以内的一名角色造成1点伤害后，你可以回复1点体力或摸一张牌。

**实现要点**：
- 「造成伤害」after hook（source===ownerId，amount>0）：若 `effectiveDistance(owner, target) <= 1` → 询问 owner 二选一。
- 二选一：回复 1 点体力（choice=true）/ 摸 1 张牌（choice=false）。
- 超时/无回应 → 不触发（与刚烈等二选一技能同构）。
- 距离 1 以内：`effectiveDistance` 最小为 1（座位相邻或自己），`<= 1` 即满足；装备 -1 马（`距离/进攻修正` vars）进一步缩短距离自动支持。

**实现差异/边界**：实现与官方描述一致。

**与标版差异**：标版狂骨为锁定技，效果为"对距离 1 以内角色造成伤害后回复等量体力（仅回血）"；界版改为被动可选技，伤害后可二选一——回复 1 点体力 **或** 摸一张牌，收益更灵活。

### 奇谋（限定技）

> **机制简述**：失去任意点体力换本回合距离缩短与出杀次数增加

**官方效果**：限定技，出牌阶段，你可以失去任意点体力并摸X张牌（X为你以此法失去的体力值），然后你本回合计算与其他角色的距离-X且使用【杀】的限制次数+X。

**实现要点**：
- use action（出牌阶段 + 自己回合 + 无 pending + 存活 + 体力≥1 + 未用过）：先以 chooseOption 问 X（1..当前体力），超时/取消不消耗限定技。
- 确认 X 后写 `player.vars['奇谋/used']`（整局一次），然后：失去体力 X →（死亡则中止）→ 摸牌 X。
- 距离-X：`vars['距离/进攻修正'] += X`（`effectiveDistance` 自动生效）+ 加标记 `奇谋/距离` 携带 `distanceVars` 同步 view；回合结束 after-hook 按 `player.vars['奇谋/距离加成']` 还原（不依赖已被清空的 turn.vars）。
- 杀次数+X：`turn.vars['奇谋/extra']` 驱动 `registerSlashExtraProvider` + 「回合用量」投影 `杀/extra/奇谋`；回合结束随 turn.vars 自动失效。

**实现差异/边界**：实现与官方描述一致。X=当前体力会进入濒死求桃，被救回则继续摸牌与增益；无人救则死亡且不摸牌、不发增益（限定技仍算已消耗）。

**与标版差异**：标版魏延的奇谋无"摸X张牌"；界版新增失去体力后摸等量牌。
