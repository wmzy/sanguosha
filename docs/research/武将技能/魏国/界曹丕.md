## 技能详解

### 行殇（被动技）

> **机制简述**：角色死亡时获其所有牌

**官方效果**：当其他角色死亡时，你可以获得其所有牌。

**实现要点**：

- 同标版曹丕·行殇实现：before hook 挂在「击杀」（target≠自己且自己存活）。
- 询问是否发动（confirm），获得手牌/装备/判定区的所有牌。
- 卡牌转移统一走「获得」atom + 「移除延时锦囊」atom 维护 pendingTricks。
- 击杀 apply 的 card-loop 因牌已被取走而成为 no-op。

**实现差异/边界**：实现与官方描述一致。与标版行殇共用同一实现。

### 界放逐（被动技）

> **机制简述**：受伤后令他人翻面并摸牌

**官方效果**：当你受到伤害后，你可以令一名其他角色翻面，并令其摸X张牌（X为你已损失体力值）。

**实现要点**：

- after hook 挂在「受到伤害后」（target=自己，amount>0）。
- 询问是否发动（confirm）→ 选目标（其他存活角色，不能是自己）→ 该目标翻面 → 摸 X 张（X=maxHealth-health，已损失体力值）。
- 翻面实现（镜像标版放逐）：flipFaceDown 加标签 "放逐/翻面" 到目标；before hook 挂「阶段开始」：目标准备阶段开始 + 有翻面标签 → 翻回正面（flipFaceUp）+ 设 skipAll 标志 + cancel；其他阶段被 skipAll 一律 cancel；before hook 挂「阶段结束」：skipAll → 主动推进回合（performSkipTurn，清过期标记 + 下一玩家 + 回合结束）。
- 满血时 X=0 不发动；无其他存活角色时不发动。
- 与标版放逐共用同一组 localVars key 与标签（'放逐/confirmed'/'放逐/target'/'放逐/翻面'/'放逐/skipAll'），跳过回合机制同构。

**实现差异/边界**：实现与官方描述一致（目标真实翻面、跳过下一回合）。与标版放逐仅结算顺序不同：界版按官方语序先翻面再摸 X 张，标版先摸 X 张再翻面。已知简化：对已背面目标再次放逐不实现官方 toggle（翻面两次翻回正面），与全引擎翻面模型一致。

### 颂威（主公技）

> **机制简述**：魏将黑判定生效后令你摸牌

**官方效果**：主公技，当其他魏势力角色的黑色判定牌生效后，其可以令你摸一张牌。

**实现要点**：

- 同标版曹丕·颂威：主公技，after hook 挂在「判定」（player≠曹丕 + faction=魏 + 判定牌黑色）。
- 询问曹丕是否摸牌（confirm）→ 摸牌 1 张。
- 仅主公曹丕可用（isLord 判定）；非主公时 hook 注册但不触发。

**实现差异/边界**：实现与官方描述一致。与标版颂威共用同一实现。
